# calculator_2

## 概要（Overview）
二つの数字を入力すると累積代入を用いた計算と、二つの数字の大小関係を調べることができます

## 使い方（Usage）
1. Pythonをインストールする
2. ターミナルで以下を実行する
3. 任意の数字を二つ入力すると計算結果と大小関係の結果が表示される

## 学んだこと（what I learned）
- float関数の使い方
- 累積代入の使い方
- input関数では入力したものは数字ではなく文字として認識されるということ

## 目的（Purpose）
- より実践的な計算プログラムを学ぶこと。
- 等号不等号の関係を調べるプログラムを学び、絞り込み機能の初歩を身に着けること。
